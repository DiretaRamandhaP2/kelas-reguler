Membuat Website Portofolio dengan Tailwind CSS

Dokumentasi pembelajaran selama 3 pertemuan (1 kali seminggu). Klik tombol Salin pada setiap kode, lalu tempel ke file Anda.

Persiapan

  • Teks editor (Visual Studio Code) dan browser (Chrome/Edge).
  • Koneksi internet, karena Tailwind, ikon, font, dan gambar dimuat lewat CDN. Ikon memakai Bootstrap Icons (hanya ikon, bukan framework Bootstrap).

Struktur folder:

portofolio/
 ├─ index.html   (struktur halaman + class Tailwind)
 └─ style.css    (CSS tambahan yang kecil)

Kamus singkat class Tailwind

p-4, px-4, py-4 Padding semua sisi, kiri-kanan, atas-bawah
mt-4, mb-4 Margin atas, margin bawah
flex, grid, gap-4 Tata letak fleksibel, grid, dan jarak antar item
text-xl, font-bold Ukuran dan ketebalan huruf
bg-white, text-hijau Warna latar dan warna teks
rounded-lg, shadow-md Sudut membulat dan bayangan
md:..., lg:... Berlaku mulai lebar layar 768px (md) atau 1024px (lg); tanpa prefix berarti semua ukuran
hover:..., focus:... Berlaku saat kursor di atas elemen atau kolom sedang diisi
w-[90%] Nilai bebas dalam kurung siku

Minggu 1: Fondasi, Navbar & Hero

Tujuan pembelajaran

  • Memasang Tailwind CSS lewat CDN dan mengatur warna kustom
  • Memahami class utility (padding, margin, flex, grid, warna)
  • Membuat navbar responsif dengan hamburger
  • Membuat hero dua kolom dengan kartu profil

1. Kerangka halaman

Buat folder portofolio berisi index.html dan style.css. Tempel kerangka ini ke index.html. Blok tailwind.config mendaftarkan warna hijau sehingga bisa dipakai sebagai bg-hijau atau text-hijau. Komentar seperti <!-- NAVBAR --> adalah tempat kode tiap bagian ditempel.

index.html HTML 
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Portfolio Saya</title>

  <!-- Tailwind CSS (CDN) -->
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    // Warna dan font kustom, bisa dipakai sebagai class: bg-hijau, text-hijau, font-sans, dst.
    tailwind.config = {
      theme: {
        extend: {
          colors: {
            hijau: { DEFAULT: '#5C7C64', tua: '#4a6651', muda: '#A8E0B5', badge: '#D3E0D6' },
            latar: '#F5F5F5'
          },
          fontFamily: { sans: ['Inter', 'sans-serif'] }
        }
      }
    }
  </script>

  <!-- Ikon dan font -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css" rel="stylesheet">
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;700&display=swap" rel="stylesheet">

  <!-- CSS tambahan -->
  <link href="style.css" rel="stylesheet">
</head>
<body class="bg-latar font-sans text-gray-900">

  <!-- NAVBAR -->
  <!-- HERO -->
  <!-- TENTANG -->
  <!-- PROJECT -->
  <!-- KONTAK -->
  <!-- FOOTER -->

</body>
</html>

2. Navbar

Ganti komentar <!-- NAVBAR -->. Class hidden menyembunyikan menu di HP, sedangkan lg:flex menampilkannya mendatar di layar besar. Tombol hamburger memakai onclick untuk menambah atau menghapus class hidden.

index.html HTML 
<nav class="sticky top-0 z-50 bg-white shadow-md">
  <div class="mx-auto flex max-w-6xl items-center justify-between px-4 py-4">
    <a href="#home" class="flex items-center gap-2 text-2xl">
      <i class="bi bi-code-slash"></i>Portfolio <span class="text-hijau">Saya</span>
    </a>
    <!-- Tombol hamburger: hanya tampil di bawah layar lg -->
    <button class="text-3xl lg:hidden" aria-label="Menu"
            onclick="document.getElementById('menu').classList.toggle('hidden')">
      <i class="bi bi-list"></i>
    </button>
    <!-- Menu: tersembunyi di HP, tampil mendatar di layar lg -->
    <ul id="menu" class="absolute left-0 top-full hidden w-full flex-col gap-4 bg-white px-4 pb-4 shadow-md lg:static lg:flex lg:w-auto lg:flex-row lg:gap-8 lg:p-0 lg:shadow-none">
      <li><a href="#home" class="font-medium text-hijau">Home</a></li>
      <li><a href="#tentang" class="font-medium text-gray-600 hover:text-hijau">Tentang</a></li>

      <li><a href="#kontak" class="font-medium text-gray-600 hover:text-hijau">Kontak</a></li>
    </ul>
  </div>
</nav>

4. style.css

Tempel ke style.css. Karena Tailwind sudah mengurus hampir semua tampilan, file ini hanya berisi gulir halus.

style.css CSS 
/* Tailwind sudah mengurus hampir semua tampilan dan responsive lewat class.
   File ini hanya untuk CSS tambahan yang kecil. */

/* Gulir halus saat menu diklik */
html { scroll-behavior: smooth; }

/* Hormati pengguna yang mematikan animasi di perangkatnya */
@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto; }
}
Tugas mandiri: Ganti nama, kampus, dan deskripsi dengan data Anda. Ubah nilai hijau di tailwind.config ke warna favorit dan amati seluruh halaman berubah.

Minggu 3: Kontak, Footer & Uji Responsive

Tujuan pembelajaran

  • Membuat form dengan styling input berbasis utility
  • Memakai state hover: dan focus:
  • Membuat footer dengan ikon sosial media
  • Menguji responsive lewat DevTools

1. Section Kontak

Ganti komentar <!-- KONTAK -->. Class focus:ring-2 memberi cincin warna saat kolom diisi. Atribut required dan type="email" memvalidasi isian otomatis, dan onsubmit menampilkan pesan terima kasih tanpa backend.

index.html HTML 
<section id="kontak" class="scroll-mt-20 bg-gradient-to-b from-hijau to-hijau-muda py-12 text-white">
  <div class="mx-auto max-w-6xl px-4">
    <div class="mb-12 text-center">
      <h2 class="text-3xl font-semibold">Kontak Saya</h2>
      <p class="mt-2">Silakan isi formulir di bawah ini jika ingin terhubung atau memberikan masukan.</p>
    </div>
    <form class="mx-auto max-w-3xl rounded-3xl bg-white p-6 text-gray-900 shadow-xl md:p-12"
          onsubmit="event.preventDefault(); alert('Terima kasih! Pesan Anda sudah terkirim.'); this.reset();">
      <div class="mb-4 grid gap-4 md:grid-cols-2">
        <div>
          <label for="nama" class="mb-1 block">Nama Lengkap</label>
          <input type="text" id="nama" placeholder="Masukkan nama lengkap" required class="w-full rounded-lg border border-gray-300 bg-gray-100 px-4 py-3 focus:border-hijau focus:outline-none focus:ring-2 focus:ring-hijau/30">
        </div>
        <div>
          <label for="email" class="mb-1 block">Email</label>
          <input type="email" id="email" placeholder="nama@email.com" required class="w-full rounded-lg border border-gray-300 bg-gray-100 px-4 py-3 focus:border-hijau focus:outline-none focus:ring-2 focus:ring-hijau/30">
        </div>
      </div>
      <div class="mb-4">
        <label for="alamat" class="mb-1 block">Alamat</label>
