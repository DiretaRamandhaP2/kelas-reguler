Membuat Website Portofolio dengan Bootstrap 5

Dokumentasi pembelajaran selama 3 pertemuan (1 kali seminggu). Klik tombol Salin pada setiap kode, lalu tempel ke file Anda.

Persiapan

  • Teks editor (Visual Studio Code) dan browser (Chrome/Edge).
  • Koneksi internet, karena Bootstrap, ikon, font, dan gambar dimuat lewat CDN.

Struktur folder:

portofolio/
 ├─ index.html   (struktur halaman)
 └─ style.css    (custom CSS dan responsive)

Minggu 1: Fondasi, Navbar & Hero

Tujuan pembelajaran

  • Memahami struktur folder dan memasang Bootstrap lewat CDN
  • Membuat navbar responsif (hamburger di layar kecil)
  • Membuat hero dua kolom dengan kartu profil
  • Mengatur warna dengan CSS variable

1. Kerangka halaman

Buat folder portofolio, lalu file index.html dan style.css. Tempel kerangka ini ke index.html. Komentar seperti <!-- NAVBAR --> adalah tempat kode tiap bagian ditempel.

index.html HTML 
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Portfolio Saya</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css" rel="stylesheet">
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;700&display=swap" rel="stylesheet">
  <link href="style.css" rel="stylesheet">
</head>
<body>

  <!-- NAVBAR -->
  <!-- HERO -->
  <!-- TENTANG -->
  <!-- PROJECT -->
  <!-- KONTAK -->
  <!-- FOOTER -->

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>

4. CSS minggu 1

Tempel ke style.css. Warna disimpan di :root supaya mudah diganti di satu tempat.

.text-hijau { color: var(--hijau-utama); }

Tugas mandiri: Ganti nama, kampus, dan deskripsi dengan data Anda sendiri. Coba ubah --hijau-utama ke warna favorit dan lihat hasilnya.

Minggu 3: Kontak, Footer & Responsive

Tujuan pembelajaran

  • Membuat form dengan komponen form Bootstrap
  • Membuat footer dengan ikon sosial media
  • Menulis media query untuk tampilan HP dan tablet
  • Menguji responsive lewat DevTools

1. Section Kontak

Ganti komentar <!-- KONTAK -->. Atribut required dan type="email" memvalidasi isian otomatis. Atribut onsubmit menampilkan pesan terima kasih tanpa backend.

index.html HTML 
<section id="kontak" class="bg-gradasi text-white py-5">

3. CSS minggu 3 & responsive

Tambahkan di bawah CSS minggu 2. Bagian @media mengubah tampilan sesuai lebar layar. Buka DevTools (F12) lalu klik ikon perangkat untuk mengujinya.

style.css CSS 
/* ===== Form kontak ===== */
.kartu-form { max-width: 900px; border-radius: 1.5rem; }
.form-control { background: #f0f0f0; }
.form-control:focus {
  border-color: var(--hijau-utama); box-shadow: 0 0 0 .2rem rgba(92, 124, 100, .25);
}

/* ===== Footer ===== */
footer { background: #000; color: #bbb; }
.ikon-sosial {
  width: 42px; height: 42px; border-radius: 50%; background: #4d4d4d; color: #fff;
  display: inline-flex; align-items: center; justify-content: center; transition: background .3s;
}
.ikon-sosial:hover { background: var(--hijau-utama); color: #fff; }
.pil-footer { display: inline-block; background: #25302a; border-radius: 1rem; padding: .9rem 2rem; font-weight: 500; }

/* ===== Responsive ===== */
@media (max-width: 991px) {
  .hero { padding: 2.5rem 0; }
}
@media (max-width: 767px) {
  .hero .btn { width: 100%; }          /* tombol hero tersusun penuh */
  section.py-5 { padding-top: 2rem !important; padding-bottom: 2rem !important; }
}
@media (max-width: 575px) {
  .avatar { width: 180px; height: 180px; font-size: 3rem; border-width: 7px; }
  .kartu-form { padding: 1.5rem !important; }
}
Tugas mandiri: Ganti link sosial media dengan milik Anda, lalu tes tampilan di lebar 375px (HP) dan 768px (tablet). Catat bagian yang perlu diperbaiki.
